# Vaishnavi / Digital World

A cinematic, responsive portfolio world built with React, TypeScript, and Vite. The experience uses CSS depth, exhibition-style project artifacts, a timeline installation, technology constellation, and digital certificate archive.

## Run locally

```bash
npm install
npm run dev
```

The project intentionally keeps content in `src/data.ts` so the provided factual information can be swapped in without changing the world layout.
